Each item below can be opened to see the complete answer, SQL code, expected output, explanation and copy button.

1(a) Schema Creation – Create all 5 tables

DDL

Answer: Create Department, Faculty, Student, Course and Enrollment tables.

CREATE TABLE Department (
    DeptID INT PRIMARY KEY,
    DeptName VARCHAR(100) NOT NULL,
    Location VARCHAR(100)
);

CREATE TABLE Faculty (
    FacultyID INT PRIMARY KEY,
    FacultyName VARCHAR(100) NOT NULL,
    DeptID INT,
    Email VARCHAR(100),
    FOREIGN KEY (DeptID) REFERENCES Department(DeptID)
);

CREATE TABLE Student (
    StudentID INT PRIMARY KEY,
    StudentName VARCHAR(100) NOT NULL,
    DOB DATE,
    DeptID INT,
    Email VARCHAR(100),
    FOREIGN KEY (DeptID) REFERENCES Department(DeptID)
);

CREATE TABLE Course (
    CourseID INT PRIMARY KEY,
    CourseName VARCHAR(100) NOT NULL,
    DeptID INT,
    Credits INT,
    FOREIGN KEY (DeptID) REFERENCES Department(DeptID)
);

CREATE TABLE Enrollment (
    EnrollmentID INT PRIMARY KEY,
    StudentID INT,
    CourseID INT,
    Semester VARCHAR(20),
    Grade VARCHAR(5),
    FOREIGN KEY (StudentID) REFERENCES Student(StudentID),
    FOREIGN KEY (CourseID) REFERENCES Course(CourseID)
);
Explanation: PRIMARY KEY uniquely identifies each row. FOREIGN KEY connects related tables.

Expected result

Question 7: Views and Materialized Views

Complete answer with definition, SQL, output and refresh.

7.1 Create Standard View

VIEW

Definition: A standard view is a virtual table defined by a saved SQL query.

CREATE VIEW CS_Students_View AS
SELECT StudentID, StudentName, Email
FROM Student
WHERE DeptID = (
    SELECT DeptID
    FROM Department
    WHERE DeptName = 'Computer Science'
);
View CS_Students_View created successfully.

7.2 Query Standard View

SELECT

7.3 Create Materialized View

MATERIALIZED VIEW

Definition: A materialized view physically stores the result set and can be refreshed periodically.

CREATE MATERIALIZED VIEW Department_Student_Count AS
SELECT d.DeptName, COUNT(s.StudentID) AS TotalStudents
FROM Department d
LEFT JOIN Student s ON d.DeptID = s.DeptID
GROUP BY d.DeptName;
Materialized view Department_Student_Count created successfully.
