Question 1 – University Database

1(a) Schema Creation (DDL)

DDL
CREATE TABLE Department (DeptID INT PRIMARY KEY, DeptName VARCHAR(100) NOT NULL, Location VARCHAR(100));

CREATE TABLE Faculty (FacultyID INT PRIMARY KEY, FacultyName VARCHAR(100) NOT NULL, DeptID INT, Email VARCHAR(100), FOREIGN KEY (DeptID) REFERENCES Department(DeptID));

CREATE TABLE Student (StudentID INT PRIMARY KEY, StudentName VARCHAR(100) NOT NULL, DOB DATE, DeptID INT, Email VARCHAR(100), FOREIGN KEY (DeptID) REFERENCES Department(DeptID));

CREATE TABLE Course (CourseID INT PRIMARY KEY, CourseName VARCHAR(100) NOT NULL, DeptID INT, Credits INT, FOREIGN KEY (DeptID) REFERENCES Department(DeptID));

CREATE TABLE Enrollment (EnrollmentID INT PRIMARY KEY, StudentID INT, CourseID INT, Semester VARCHAR(20), Grade VARCHAR(5), FOREIGN KEY (StudentID) REFERENCES Student(StudentID), FOREIGN KEY (CourseID) REFERENCES Course(CourseID));

Remember: Primary Key = unique row identifier. Foreign Key = relationship between tables.

1(b1) Students in Computer Science

JOIN
SELECT s.*
FROM Student s
JOIN Department d ON s.DeptID = d.DeptID
WHERE d.DeptName = 'Computer Science';

1(b2) Courses with faculty names

JOIN
SELECT c.CourseName, f.FacultyName
FROM Course c
JOIN Faculty f ON c.DeptID = f.DeptID;

This follows the answer you supplied: course and faculty are matched through DeptID.

1(b3) Student enrollments with grades

JOIN
SELECT e.EnrollmentID, s.StudentName, c.CourseName, e.Semester, e.Grade
FROM Enrollment e
JOIN Student s ON e.StudentID = s.StudentID
JOIN Course c ON e.CourseID = c.CourseID;

1(b4) Count students in each department

GROUP BY
SELECT d.DeptName, COUNT(s.StudentID) AS TotalStudents
FROM Department d
LEFT JOIN Student s ON d.DeptID = s.DeptID
GROUP BY d.DeptID, d.DeptName;

1(b5) Departments with locations

SELECT
SELECT DeptName, Location
FROM Department;

1(b6) Faculty with department names

JOIN
SELECT f.FacultyName, d.DeptName
FROM Faculty f
JOIN Department d ON f.DeptID = d.DeptID;

Question 3 – SQL Functions

3.1 String Functions

STRING
SELECT UPPER(DeptName), LOWER(Location) FROM Department;
SELECT CONCAT(FacultyName, ' - ', Email) AS FacultyDetails FROM Faculty;
SELECT SUBSTRING(StudentName, 1, 3) FROM Student;
SELECT StudentName, LENGTH(StudentName) AS NameLength FROM Student;

UPPER/LOWER = case conversion • CONCAT = combine text • SUBSTRING = extract part • LENGTH = string length.

3.2 Numeric Functions

NUMERIC
SELECT ROUND(123.4567, 2);
SELECT ABS(-50);
SELECT CEIL(45.2), FLOOR(45.8);
SELECT MOD(10, 3), POWER(2, 3);

ROUND = round number • ABS = absolute value • CEIL/FLOOR = upper/lower integer • MOD = remainder • POWER = exponent.

3.3 Date and Time Functions

DATE
SELECT CURRENT_DATE();
SELECT StudentName, EXTRACT(YEAR FROM DOB) AS BirthYear FROM Student;
SELECT DATEDIFF(CURRENT_DATE(), DOB) AS AgeInDays FROM Student;
SELECT DATE_ADD(CURRENT_DATE(), INTERVAL 7 DAY);

These functions return or calculate date/time information. Exact syntax can vary by DBMS.

Question 5 – Joins and Set Operations

5.1 Inner Join

INNER
SELECT Student.StudentName, Enrollment.Grade
FROM Student
INNER JOIN Enrollment ON Student.StudentID = Enrollment.StudentID;

Returns matching rows from both tables.

5.2 Equi-Join

=
SELECT Faculty.FacultyName, Department.DeptName
FROM Faculty, Department
WHERE Faculty.DeptID = Department.DeptID;

5.3 Natural Join

NATURAL
SELECT *
FROM Student
NATURAL JOIN Department;

5.4 Left Outer Join

LEFT
SELECT Department.DeptName, Student.StudentName
FROM Department
LEFT OUTER JOIN Student ON Department.DeptID = Student.DeptID;

5.5 Right Outer Join

RIGHT
SELECT Student.StudentName, Department.DeptName
FROM Student
RIGHT OUTER JOIN Department ON Student.DeptID = Department.DeptID;

5.6 Full Outer Join

FULL
SELECT Student.StudentName, Department.DeptName
FROM Student
FULL OUTER JOIN Department ON Student.DeptID = Department.DeptID;

Support for FULL OUTER JOIN varies by DBMS.

5.7 UNION

SET

UNION
SELECT DeptID FROM Student;

5.8 INTERSECT

SET
SELECT DeptID FROM Faculty
INTERSECT
SELECT DeptID FROM Student;

5.9 Set Difference

EXCEPT / MINUS
SELECT DeptID FROM Department
EXCEPT
SELECT DeptID FROM Student;

Some DBMS use MINUS instead of EXCEPT.

Question 7 – Views and Materialized Views

7.1 Create Standard View

VIEW

Definition: A virtual table defined by a saved SQL query.

CREATE VIEW CS_Students_View AS
SELECT StudentID, StudentName, Email
FROM Student
WHERE DeptID = (SELECT DeptID FROM Department WHERE DeptName = 'Computer Science');

7.2 Query View

SELECT
SELECT * FROM CS_Students_View;

7.3 Create Materialized View

MATERIALIZED

Definition: A view whose result set is physically stored and can be refreshed periodically.

CREATE MATERIALIZED VIEW Department_Student_Count AS
SELECT d.DeptName, COUNT(s.StudentID) AS TotalStudents
FROM Department d
LEFT JOIN Student s ON d.DeptID = s.DeptID
GROUP BY d.DeptName;

7.4 Query Materialized View

SELECT
SELECT * FROM Department_Student_Count;

7.5 Refresh Materialized View

REFRESH
REFRESH MATERIALIZED VIEW Department_Student_Count;

Materialized-view syntax/support depends on the DBMS.
